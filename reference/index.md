# Package index

## All functions

- [`align_phylopred_inputs()`](https://alrobles.github.io/phylopred/reference/align_phylopred_inputs.md)
  : Align incidence matrix and phylogenetic distance matrix
- [`beetleTreeInteractions`](https://alrobles.github.io/phylopred/reference/beetleTreeInteractions.md)
  : Beetle tree interaction table.
- [`bootstrap_phylopred_model()`](https://alrobles.github.io/phylopred/reference/bootstrap_phylopred_model.md)
  : Bootstrap a phylopred logistic regression model
- [`cluster_bootstrap_phylopred()`](https://alrobles.github.io/phylopred/reference/cluster_bootstrap_phylopred.md)
  : Cluster bootstrap for pairwise host-sharing models
- [`compare_phylopred_slopes()`](https://alrobles.github.io/phylopred/reference/compare_phylopred_slopes.md)
  : Compare host-sharing slopes between two clades
- [`evaluate_phylopred_model()`](https://alrobles.github.io/phylopred/reference/evaluate_phylopred_model.md)
  : Evaluate the predictive capacity of a pairwise host-sharing model
- [`extract_phylopred_coefficients()`](https://alrobles.github.io/phylopred/reference/extract_phylopred_coefficients.md)
  : Extract coefficients from a phylopred model or bootstrap object
- [`fish_tree`](https://alrobles.github.io/phylopred/reference/fish_tree.md)
  : Phylogenetic tree of marine fish hosts of Caligus and Lepeophtheirus
- [`fit_phylopred_model()`](https://alrobles.github.io/phylopred/reference/fit_phylopred_model.md)
  : Fit a phylopred logistic regression model
- [`fit_phylopred_pu()`](https://alrobles.github.io/phylopred/reference/fit_phylopred_pu.md)
  : Positive-unlabeled host prediction via xplus (PLUS algorithm)
- [`host_specificity_index()`](https://alrobles.github.io/phylopred/reference/host_specificity_index.md)
  : Host specificity index (S_TD) for every parasite in an interaction
  table
- [`host_threshold_metric()`](https://alrobles.github.io/phylopred/reference/host_threshold_metric.md)
  : Threshold metric f_gamma for predicted host suitability
- [`phy_dist`](https://alrobles.github.io/phylopred/reference/phy_dist.md)
  : Phylogenetic distance matrix among host data on phylopred
- [`phylo_partial_roc()`](https://alrobles.github.io/phylopred/reference/phylo_partial_roc.md)
  : Phylogenetic partial ROC (Peterson, Papes & Soberon 2008 analogue)
- [`phylopred_confidence_ellipse()`](https://alrobles.github.io/phylopred/reference/phylopred_confidence_ellipse.md)
  : Joint confidence ellipse for intercept and slope
- [`poulin_std()`](https://alrobles.github.io/phylopred/reference/poulin_std.md)
  : Poulin & Mouillot's taxonomic/phylogenetic distinctness index (S_TD)
- [`predict_phylopred_probability()`](https://alrobles.github.io/phylopred/reference/predict_phylopred_probability.md)
  : Predict host susceptibility probabilities from logistic regression
  coefficients
- [`prepare_incidence_matrix()`](https://alrobles.github.io/phylopred/reference/prepare_incidence_matrix.md)
  : Prepare an incidence matrix from an interaction table
- [`prepare_pair_data()`](https://alrobles.github.io/phylopred/reference/prepare_pair_data.md)
  : Build a pairwise host-sharing data set from an interaction table
- [`taxonomic_step_matrix()`](https://alrobles.github.io/phylopred/reference/taxonomic_step_matrix.md)
  : Build a taxonomic step-distance matrix (Poulin & Mouillot scale)
- [`validate_host_prediction()`](https://alrobles.github.io/phylopred/reference/validate_host_prediction.md)
  : Leave-hosts-out validation of host predictions
