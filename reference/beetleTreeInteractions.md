# Beetle tree interaction table.

A dataset of beetles and genues of host trees. Original information is
avaliable in <https://www.barkbeetles.info/>

## Usage

``` r
beetleTreeInteractions
```

## Format

A data frame with 565 rows and 2 variables:

- beetle:

  Species of bark beetles

- genus:

  Genus of host tree of bark beetles

## Source

<https://www.barkbeetles.info/>

## Details

We use this interaction tables to construct an incidence matrix. This is
a table representation of a bipartite graph
