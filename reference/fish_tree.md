# Phylogenetic tree of marine fish hosts of Caligus and Lepeophtheirus

A phylogenetic tree (class `phylo`) of 625 marine fish species that are
recorded hosts of sea lice of the genera *Caligus* and *Lepeophtheirus*
in the `cofid` copepod-fish interaction database. The tree is pruned
from the Fish Tree of Life actinopterygian phylogeny (Rabosky and
colleagues 2018, actinopt_12k_raxml). Tip labels are binomial species
names with spaces.

## Usage

``` r
fish_tree
```

## Format

A `phylo` object with 625 tips.

[doi:10.1038/s41586-018-0273-1](https://doi.org/10.1038/s41586-018-0273-1)
